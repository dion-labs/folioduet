## Changes and prevention

Neural audio ignores rejected play promises and media callbacks belonging to stopped/replaced players. A current media error and promise rejection trigger fallback once. Audio uses the standard MPEG MIME type and reports provider/error category without private text or keys. These changes repair a demonstrated lifecycle defect; they do not establish that every cloud-browser codec/provider failure has the same cause.

Privacy and terms pages are generated from the same legal text as the app. Unknown paths and missing assets use a real static 404 page. Only historical `/v2` routes redirect to the reader. The live checker now rejects soft 404s and legal routes that only return an empty SPA shell.

The supplied `docs/qa/github-actions.example.yml` installs Node 22 and Java 21 and runs unit tests, build, all rules suites, and dependency audit. It is a template, not an active workflow: GitHub rejected workflow creation because the current OAuth credential lacks workflow scope. Rules coverage includes FolioDuet owner CRUD, anonymous ownership, denial across identities, independent same-owner contexts, and deletion scoped to a disposable book, plus existing feedback and Boxie compatibility.
